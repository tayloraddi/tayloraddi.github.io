Fashion UX AI Website

Summer 2026 research internship. An AI tool that reviews fashion websites and apps and tells you how to make them easier to shop.

  • Python
  • FastAPI
  • Google Gemini API
  • HTML, CSS, JavaScript
  • Render

Live siteCode

The problem
Fashion sites lose shoppers over small things: buried buttons, confusing navigation, unclear sizing. I wanted a faster way to spot those problems from a real shopper’s point of view.
What I built
A full-stack web app: you upload a screenshot of a fashion site, choose a user persona, and get a UX score plus feedback on first impression, visual design, usability, trust, shopping experience, pain points, and recommended fixes.
What I did
Built a Python (FastAPI) backend that sends the screenshot and persona details to Google’s Gemini API, built the interface in HTML, CSS, and JavaScript, and deployed it on Render, using Cursor to build. Users can pick a preset persona (college student, young professional, fashion enthusiast) or enter their own age, location, and occupation, and the AI writes its feedback from that person’s point of view. [Add how many sites you tested.]
What I learned
AI responses don’t always come back in a tidy format, so I wrote code to pull out the score, split the feedback into sections, and fix garbled characters. I also told the AI to describe only what’s visible in the screenshot so it wouldn’t invent features.
