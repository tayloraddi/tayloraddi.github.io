Fashion UX AI Website

Summer 2026 research internship. An AI tool that reviews fashion websites and apps and tells you how to make them easier to shop.

  • Python
  • FastAPI
  • Google Gemini API
  • HTML, CSS, JavaScript
  • Render

Live siteCode

The problem
Fashion sites lose shoppers over small things: buried buttons, confusing navigation, unclear sizing. I wanted a faster way to spot those problems from a real shopper’s point of view.
What I built
A full-stack web app: you upload a screenshot of a fashion site, choose a user persona, and get a UX score plus feedback on first impression, visual design, usability, trust, shopping experience, pain points, and recommended fixes.
What I did
Built a Python (FastAPI) backend that sends the screenshot and persona details to Google’s Gemini API, built the interface in HTML, CSS, and JavaScript, and deployed it on Render, using Cursor to build. Users can pick a preset persona (college student, young professional, fashion enthusiast) or enter their own age, location, and occupation, and the AI writes its feedback from that person’s point of view.
What I learned
AI responses don’t always come back in a tidy format, so I wrote code to pull out the score, split the feedback into sections, and fix garbled characters. I also told the AI to describe only what’s visible in the screenshot so it wouldn’t invent features.

Lace & Bloom

A film and TV review blog with a matching merch shop, styled like an indie film studio with a soft pink identity.

  • WordPress
  • WooCommerce
  • Custom CSS
  • Content writing

Live site

The problem
I wanted a film and TV blog that feels like an indie studio, with a shop attached. The inspiration was Letterboxd crossed with A24, with a soft pink look drawn from The Virgin Suicides and Nosferatu.
What I built
A WordPress site with three film and three TV reviews, plus a WooCommerce shop with five products (a mug, baby tee, movie poster, sweatshirt, and bag) in apparel and accessories categories, with sizes for the clothing.
What I did
Customized the Twenty Twenty-Five theme in the site editor with my own color palette, Google fonts, and spacing in Global Styles. Designed each review page with the block editor, wrote custom CSS so posters turn from black and white to color on hover, built a category-filtered query loop that keeps the homepage previews up to date automatically, and saved a block group as a reusable pattern. Set up the shop in WooCommerce, including size variations for the clothing.
What I learned
I used AI to draft product and review descriptions and learned I had to be specific and add my own detail. It was more useful for fixing problems, like a query loop hidden inside a pattern, than for creative direction.

Disaster Tweet Parser

A Java program from my intro programming course that turns a tweet asking for help during a natural disaster into a clear, organized summary.

  • Java
  • Eclipse
  • String manipulation

Source code available on request

The problem
In an emergency, tweets carry key details like what kind of help is needed and where, but they’re hard to scan quickly.
What I built
A Java program that reads a tweet tagged with #typ, #det, #loc, #lat, and #lng, pulls out each part, and prints a labeled summary of the type, detail, location, latitude, and longitude.
What I did
Used string methods like indexOf and substring to find each tag and extract the text after it, then cleaned up the results by trimming spaces, capitalizing the type, and replacing commas.
What I learned
Debugging, documenting my code, and testing in small steps made the program more accurate and easier to read.
